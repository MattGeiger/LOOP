# Release Notes

What's new in LOOP, newest first.

## Version 1.1 — November 25, 2026

- Every button has an icon, and each icon means the same thing everywhere.
- Click a step at the top of LOOP Setup to go back to it.
- Clearer button names, such as Start fullscreen playback and Finish setup (go live).

## Version 1.0 — November 25, 2026

- The video loops by itself and switches to a new download when the current loop ends.
- Staff Display Tools: get a new video, show the idle screen, restart the video, check the display's status and
  Performance History.
- LOOP Setup walks through first-time setup; Settings changes it later.
- Colors are checked for readable contrast, with a one-click readable shade.
- Burn-in tests check a new display before it goes into service.
- Read-only mode protects the SD card; videos and history are kept on the USB drive.
- Update Software installs updates safely, with the idle screen showing meanwhile.
- The display starts with your logo, and every window fits HD televisions.
